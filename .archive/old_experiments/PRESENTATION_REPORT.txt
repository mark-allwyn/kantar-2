INSIGHTS FROM ANALYSIS
================================================================================

PATTERN: Question Type Matters More Than Expected

✓ SSR Works Well For:
   - Concrete behavioral questions (excitement, relevance)
   - Emotional/feeling-based responses
   - Personal fit assessments ('relevant to me')
   - Questions with clear semantic progressions

✗ SSR Struggles With:
   - Abstract evaluative judgments (believability, uniqueness)
   - Questions requiring cultural/market context
   - Category expertise-dependent assessments
   - Multi-level scales with subtle distinctions

KEY FINDING:
   The systematic conservative bias is NOT universal - it's
   construct-specific. This suggests the issue is in how the LLM
   interprets different question types, not the SSR methodology itself.

RECOMMENDED NEXT STEPS FOR EXPERIMENTATION
--------------------------------------------------------------------------------

Based on the pattern that SSR works for some question types but not others,
we recommend focused experiments to understand and address the root causes:

EXPERIMENT 1: Isolate Response Generation vs SSR Mapping
  Objective: Determine if bias is in LLM responses or SSR conversion

  Objective: Understand what language LLM generates for failing questions

  Time: 1 day
  What we'll learn: If responses are genuinely conservative or mapping fails

EXPERIMENT 3: Test Question-Specific Prompt Engineering
  Objective: Fix abstract evaluative questions with targeted prompts
  Method: Add construct-specific context for failing questions
  Time: 3-5 days
  What we'll learn: If prompt customization can fix the bias

EXPERIMENT 4: Anchor Text Systematic Redesign
  Objective: Improve anchors for failing questions based on learnings
  Method: Apply successful patterns from working questions
  Time: 1-2 weeks
  What we'll learn: If anchor design can address distribution mismatch

EXPERIMENT 5: Alternative Embedding Models
  Objective: Test if higher-dimensional embeddings improve SSR
  Method: Compare text-embedding-3-small vs text-embedding-3-large
  Time: 2-3 days
  What we'll learn: If embedding quality affects semantic similarity

PRIORITIZATION:
